# Introduction 

In this assignment, we analyze raw wrist-worn accelerometer data (0_z.csv) collected from an Axivity AX3 sensor. 

Our main goals are:

Compute ENMO (Euclidean Norm Minus One): Calculate the overall body acceleration while removing the constant effect of gravity. Integrate Over Epochs: Aggregate and plot the ENMO activity over intervals of 10s, 30s, and 60s.
